# F&M Cafe

This aim of this project is to create a fun receipt printer for my kids that they can use when pretending to work in cafe, ice cream shop, restaurant, etc or other games where printing things on little pieces of paper could be fun. 

The hardware for the project is:
 - a Raspberry Pi
 - which is connected to an Epson TM-T20II thermal receipt printer

We will mostly used Python. We should use uv for package management.

We might build a web page to allow for testing the code locally (i.e. to display a mock up of the expected printer output)
